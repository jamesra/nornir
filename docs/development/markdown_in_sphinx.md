# Markdown in the monodoc

This file is **MyST Markdown** included in the Sphinx build via `myst_parser`.

Use **reStructuredText** (`.rst`) for the main manual so directives, toctrees, and cross-references stay consistent. Use Markdown when a short page is enough or when you are migrating existing `.md` content.

See `docs/conf.py` for enabled MyST extensions.
