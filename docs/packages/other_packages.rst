Other repositories in the umbrella
====================================

These components are part of the same workspace but are documented primarily via their package ``README.md`` files and optional future monodoc sections:

* **nornir-pyre** — interactive registration and visualization (PyQt / OpenGL stack).
* **nornir-docker** — container definitions for development and workers.
* **nornir-web**, **nornir-volumecontroller**, **nornir-volumemodel** — supporting services and models.

When a package gains stable public APIs worth autodoc, add a section under :doc:`index` and API stubs under ``docs/api/``.
