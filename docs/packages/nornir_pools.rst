nornir-pools
============

Thread, process, subprocess, and cluster **pool** abstractions so the same task code can run locally or on a cluster.

* **Python import:** ``nornir_pools``
* **Which pool to call, and stage shutdown:** :doc:`../performance/pools`

Install from Git (see also the package ``README.md``)::

  pip install git+https://github.com/nornir/nornir-pools.git --upgrade

**API reference:** :doc:`../api/nornir_pools`
